# Design

Use the existing clean-source qualification and gated OIDC release workflow. Include all seven allowlisted .NET packages, matching symbols and the unchanged 0.2.0 Python/TypeScript author SDKs. Retain exact artifact hashes and verify public NuGet payloads after indexing. Correct the invalid-array exception only after a failing packed regression; API and wire fields remain unchanged.

Preserve historical evidence and record the explicit cooperative reuse, native execution and loopback TLS boundaries in the audit. The pre-publication audit is not a publication receipt.
