# Privacy

## Operator and contact

This documentation website is operated by Norbert Heinz Rosenwinkel. Contact and postal details are in the [imprint](imprint.md).

## Website delivery

This is a static documentation site. The hosting server receives connection information needed to deliver pages, including your IP address, requested URL and the headers sent by your browser. The server may record these in access and error logs for operation and troubleshooting.

The site runs on the same operator-managed hosting infrastructure as Stratara. Its [hosting and data-protection information](https://stratara.tech/legal/privacy.html) describes the operator's infrastructure and how to exercise data-protection rights. Questions about the handling of connection records can be sent to the contact in the imprint.

## Search and browser preferences

Documentation search runs in your browser against an index downloaded from this website. Search queries are not sent to a search service. The documentation theme uses browser local storage to remember functional preferences such as the selected color scheme.

This website's build includes no analytics tag, advertising script, tracking pixel or external font service. Links to GitHub, NuGet and other external websites open those services only when followed; their own privacy information then applies.
