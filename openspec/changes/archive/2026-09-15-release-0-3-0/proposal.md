## Why

Optional local MCP tools are implemented but not publicly packaged, and adoption material still describes them as future work.

## What Changes

Qualify and release the existing MCP scope as 0.3.0, correct continuation rejection to meet the current specification, refresh reviewed dependencies, and align the website, guides, package readme and executable example.

## Capabilities

No new capability: the MCP baseline already requires unsupported continuations to fail.

## Impact

Four core NuGet packages and exact compatibility declarations; development tooling, examples, documentation and release evidence. Native remains the default. Remote MCP, new platforms and additional MCP interactions remain outside scope.
