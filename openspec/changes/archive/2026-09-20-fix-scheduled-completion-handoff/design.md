# Design

Keep the computed result/error until the dispatch finally block. Under the same scheduler lock, release active ownership, signal idle, wake admission and only then complete the public task. Asynchronous continuations can no longer overtake the lifecycle update. Concurrent later work may still legitimately make the registration active again.

Source and packed multilingual reuse suites each pass 1,036 assertions, including 60 new post-completion activity checks. The existing constructor signatures and core style gate are preserved.
