# Evaluate trust-based reuse

Compare fresh containers, fresh Python processes inside reusable containers, and cooperative SDK-style reset inside reusable Python processes. Alternate actual plugin modules and customer identities. Retain performance and negative isolation evidence before changing the published SDK or the current host's no-cross-tenant-reuse contract. Author examples must explain required cleanup and the limits of cooperation. This is an experimental harness, not a new production isolation guarantee.
