Consumer examples need the public MCP method constants in an installable package.

## What Changes
Publish the four core packages at 0.3.1 with public MCP invocation constants and internal protocol identifier cleanup. Align exact compatibility declarations and remove source-only adoption notes.

## Impact
Core package metadata, consumer examples, public API baseline, documentation and DEV draft. No new transport, protocol values, dependencies or platform guarantees.
