# Composition and Gateway package self-review

Reviewed 2026-09-18 for [PR #24](https://github.com/yesbert/WeavePort/pull/24), against `main` at `6447e58`. This is an author-performed manual review with executable regression checks, not an independent second-person review. Copilot did not review the change because its account quota was exhausted.

## Finding and correction

**P2 — Invalid discovery JSON escapes the protocol validation error.** `RemotePluginClient.GetTenantAsync` called `TryGetProperty` before checking that the response was an object and `TryGetInt32` before checking that `protocol` was a number. For example, an authenticated server replying with `[]` raised `InvalidOperationException` instead of the intended `InvalidDataException`. A string or null protocol field had the same issue. Access remained denied; this was error-contract robustness, not a tenant bypass.

The packed HTTPS consumer reproduced the array case before the fix. The correction checks both JSON kinds before using the typed APIs. Eight response variants now exercise incompatible versions, array/null roots, string/null versions, and missing/numeric/blank tenants. The existing API and wire schema are unchanged. Microsoft documents the type preconditions for [TryGetProperty](https://learn.microsoft.com/en-us/dotnet/api/system.text.json.jsonelement.trygetproperty?view=net-10.0) and [TryGetInt32](https://learn.microsoft.com/en-us/dotnet/api/system.text.json.jsonelement.trygetint32?view=net-10.0).

A suspected overload ambiguity for `new RemotePluginClient(endpoint, credential, null)` was explicitly compiled and executed. It selects the original nullable-timeout overload successfully with the pinned SDK. No API change was made; the consumer retains the compatibility check.

## Verification and limits

The regression suite uses the packed NuGet dependencies, not project references. The corrected optional suite contains 104 checks, plus its API/dependency checks and the native composition suite. The final committed revision must pass `./scripts/verify.sh` in a fresh checkout; its candidate record and PR CI contain the exact source commit, assertion count and frozen artifact hashes. Local before/after diagnostic logs are retained in `artifacts/review-0.4.0/`.

No further release-blocking defect was identified in the reviewed scope. This conclusion is bounded by the executed tests: optional HTTPS/composition execution is macOS loopback with separate real worker processes, not WAN, proxy, multi-machine, hostile-plugin or optional Windows/Linux qualification. Application-wide admission, credential expiry/rotation, private-root protection and recovery of crash-orphaned files remain application responsibilities. A throwing application-supplied HTTP handler is outside the normal transport ownership tests; these tests do not claim arbitrary custom-handler fault tolerance.
