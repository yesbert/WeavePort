# Clarify platform support

## Why

The documentation foregrounded the macOS validation environment as though the product were Mac-specific.

## What Changes

Describe Windows, Linux and macOS as supported targets for trusted stdio execution. Keep current release validation, Unix-socket restrictions and platform-specific tooling explicit. Publish the validated documentation website. No runtime behavior or qualification claims change.

## Impact

README, website adoption pages, platform/status/local execution guides, generated LLM documents and static website delivery.
